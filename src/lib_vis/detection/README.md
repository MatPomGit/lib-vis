# detection

Detekcja obiektów i pozycji w pojedynczej klatce.

Detekcje pojedynczych klatek: bbox, klasa, orientacja, punkty pozy lub maska referencyjna. Adaptery mogą opakować klasyczne metody albo istniejące modele detekcji; nie wprowadzać automatycznego rozpoznawania tożsamości osób. Model i próg confidence muszą być jawne.
