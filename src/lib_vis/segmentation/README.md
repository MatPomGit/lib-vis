# segmentation

Segmentacja semantyczna lub instancyjna jednej klatki.

Maski binary/instance/semantic, etykiety klas, mapowanie do przestrzeni obrazu i źródło confidence. Przeskalowanie maski nie może ukryć interpolacji. Jeżeli segmentacja pochodzi z modelu, adapter raportuje wersję i parametry inferencji.
