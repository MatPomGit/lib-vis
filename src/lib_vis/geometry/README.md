# geometry

Geometria 2D/3D, głębia i przepływ optyczny.

Projekcje, pomiar konturów, rekonstrukcja stereowizyjna, głębia i przepływ optyczny. Wyniki dla obrazu w px, a dla przestrzeni 3D w m po potwierdzonej kalibracji. Flow między klatkami nie jest jednoznaczny z utrzymaniem track_id; te zależy do lib-track.
