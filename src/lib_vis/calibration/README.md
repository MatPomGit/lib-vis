# calibration

Parametry kamer, dystorsja, geometria projekcji.

Dane: kamera/pixel aspect, intrinsics, dystorsja, rozdzielczość, extrinsics, identyfikator kalibracji i błąd reprojekcji. Bez parametrów kalibracji nie wolno deklarować metrycznej rekonstrukcji 3D. Celem jest wykorzystanie istniejących funkcji OpenCV lub zgodnych SDK, z zapisem metadanych.
